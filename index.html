📲 Pasang / Instal Aplikasi ke Layar Utama

Aplikasi siap dipasang agar bisa dibuka layar penuh seperti aplikasi asli di Komputer maupun HP:

💻 Komputer / Laptop (Chrome / Edge):
1. Pastikan halaman dibuka lewat link web online (HTTPS, seperti GitHub Pages).
2. Klik ikon Instal ( / +) di ujung kanan kolom alamat URL browser, atau menu Titik Tiga (⋮) → Simpan dan bagikan → Instal halaman sebagai aplikasi.
3. Klik Instal (ikon otomatis muncul di Desktop & Start Menu).
🤖 Android (Chrome / Edge):
1. Ketuk ikon Titik Tiga (⋮) di pojok kanan atas browser.
2. Pilih "Tambahkan ke Layar Utama" atau "Instal Aplikasi".
3. Tekan Pasang / Install.
🍎 iPhone / iPad (Safari):
1. Ketuk ikon Bagikan / Share () di bagian bawah Safari.
2. Geser ke bawah dan pilih "Add to Home Screen" (Tambah ke Layar Utama).
3. Tekan Add / Tambah.
